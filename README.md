This application requires that you have a game setup with a "steam_settings" folder. If you are looking for a means to generate those files check my other project Steam Settings Generator.
- https://github.com/Elite-Alien/Steam-Settings-Generator

The Achievement Viewer is a application that I made to fill a role that I was missing with Drop. I use Drop-OSS for my game collection of legal games I have purchased. However, it lacks a achievement system at the moment. This helps fill that role for the time being. Making it easier to load in achievements to a applciation and keep track of them, even when the game isn't running. It's fairly simple in nature and you do have to manually set it up for each game, but it does the job. All this being said, if you wish to use this you will have to "cargo build" it. Also, if you wish to use this code or even continue on with this, fork it, and do other stuff with it expanding it, then be my guest. All I ask is that you share your changes with everyone.

To use this application you must set a game name, grab the Game ID or Appid, set the Game folders "steam_settings" folder, and find the "GSE Save" folder where the folder using the AppID is located.

<img width="400" height="383" alt="image" src=https://github.com/Elite-Alien/Achievement-Viewer/blob/main/screenshots/aw2.png  />

Once you set it up for the correct locations and it finds the JSON files needed and the "achievement_images" folder in "steam_settings" for that game. It will add the game and load in the achievements. You can force a reload if needed. Then once you play your game as the files are updated this application actively watches for changes and update based on you obtaining an achievement.

Achievements you earn are counted into your total achievements collected and you get a "Score". Any game you remove from the application will keep your achievement progress. It does not store your achievements.json files or back them up. However, it will remember the progress you had and keep it until you wish to reimport the game. You will need to back these files up yourself.

Setting a username will create the users.config.ini file for you in all games you load into this application. It will also generate you an ID that can be carried across all your games with ease. You can always regenerate an ID or set your own. Though it gets randomly generated by default once you create a username. This username will be what is displayed in the games you play, if the game grabs this data.
